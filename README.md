# powershell_tools
## Installation
### Method 1: Git Clone
#### Linux
Clone the repository:

```bash
git clone https://github.com/alims-engineering/powershell_tools.git "/Alims/engineering/powershell_tools"
```

#### Windows
Clone the repository:

```bash
git clone https://github.com/alims-engineering/powershell_tools.git "C:/Alims/engineering/powershell_tools"
```
